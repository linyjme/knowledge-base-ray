# How do I start an upload or download transfer?

## Short answer

Choose upload for local content going to server storage, or download for server content going to the computer. Confirm source, target, direction, permissions, and same-name policy before submission.

An accepted request or created task is only the beginning. The worker must start, data must progress, the task must reach a final state, and important targets should be verified independently.
