# What are group files and what can I do with them?

## Short answer

A group file library is a shared directory for collaboration. In the user portal, open **Group File Folder**, select a group library, and work with its files and folders using the actions allowed for your membership.

Depending on permission, available actions can include upload, download, sync-task creation, folder creation, deletion, and share-download link creation. These use the same basic workflows as personal files.

An action that is missing or denied is outside your assigned access for that group library. Confirm shared content before deleting it because the change can affect other members. The feature matrix lists personal and group file management for SMB, Enterprise, Cloud, and Multiple Spaces editions.
