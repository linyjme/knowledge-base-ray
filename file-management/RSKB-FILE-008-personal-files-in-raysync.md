# What are personal files in Raysync?

## Short answer

Personal files are the files and folders in your individual Raysync directory, shown under **My Files**. They are distinct from content in a shared group file library.

The actions available to your account can include upload, download, folder creation, rename, copy, move, delete, search, folder properties, supported archive decompression, preview, and sync-task creation. Visible operations depend on permissions and server configuration.

Deleting a personal file may send it to a personal recycle bin or remove it directly according to administrator policy. The feature matrix lists personal and group file management for SMB, Enterprise, Cloud, and Multiple Spaces editions.
