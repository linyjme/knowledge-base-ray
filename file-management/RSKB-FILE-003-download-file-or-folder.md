# How do I download a file or folder?

## Short answer

Select the server file or folder. Choose **Download with web** for a browser download, or **Download** for a client download. Browser progress appears in the browser's downloads; client progress appears in the client transfer list.

## Steps

1. Select the file or folder.
2. Choose the web or client download action.
3. For a client download, select a local path if prompted.
4. Monitor the corresponding download list.
5. For a completed client download, use **Open File Directory** to locate it.

Download requires permission. A share-download link permits downloading only when its creator and server settings allow it. An invite-upload link is for receiving uploads and is not a download link.
