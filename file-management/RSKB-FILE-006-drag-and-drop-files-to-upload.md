# Can I drag and drop files to upload them?

## Short answer

Yes. Open the destination in the user portal, drag a local file or folder over the Raysync file list, wait for the page to show the intended destination, and release the mouse button.

## Steps

1. Open the destination directory in Raysync.
2. Select the local files or folders in your operating system's file manager.
3. Drag them over the portal's file-list area.
4. Check the destination indicator, such as **Upload to My Files** or the current directory.
5. Release the mouse button and monitor the upload.

Drag-and-drop does not bypass upload permission, file-format limits, existing-file restrictions, antivirus scanning, or isolation.
