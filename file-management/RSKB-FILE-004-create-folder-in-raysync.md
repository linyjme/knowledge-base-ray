# How do I create a folder in Raysync?

## Short answer

Open **My Files** or a group file library where you have permission. Select **New Folder**, replace the initial **New Folder** name with the name you want, and select **Create**.

## Steps

1. Open the destination directory.
2. Select **New Folder**.
3. Enter the folder name.
4. Select **Create**.

This browser operation does not require a running client. It is separate from web folder upload, which cannot upload an empty local folder. The feature matrix lists new-folder support for SMB, Enterprise, Cloud, and Multiple Spaces editions.
