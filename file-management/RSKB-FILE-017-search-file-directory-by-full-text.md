# Can I search a file directory by full text?

## Short answer

Raysync lists full-text retrieval of a file directory for Enterprise, Cloud, and Multiple Spaces editions. It is not supported in SMB. For Enterprise, the feature entry explicitly says an additional payment is required.

The matrix does not document an end-user setup procedure or exact interface path. If the capability is unavailable, ask the administrator or license owner to confirm your edition and, for Enterprise, the additional paid-feature entitlement. Do not assume Enterprise entitlement from the edition name alone.
