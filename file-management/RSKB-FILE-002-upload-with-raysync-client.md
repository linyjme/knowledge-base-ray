# How do I upload with the Raysync client?

## Short answer

From the user portal, select **Upload with client**, choose the file or folder, and monitor the client transfer list. In the standalone desktop client, open **My Files** and select **Upload**, or drag files or folders into the client interface.

## Before you start

Install and start the desktop client or browser plug-in. Open the server directory that should receive the upload.

## Steps

1. Select **Upload with client** in the portal or **Upload** in the desktop client.
2. Choose the files or folders.
3. Open the client transfer list to check progress and file-level details.

Client upload remains subject to server permissions, file-format filters, antivirus checks, and conflict settings. Selecting local content successfully does not override those controls.
